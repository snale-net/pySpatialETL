is_regular_grid
===============

.. py:method:: spatialetl.coverage.coverage.Coverage.is_regular_grid(type='target')

   Check if the grid is regular.

   :param type: Type of the grid ("target", "source").
   :type type: str, optional

   :returns: True if the grid is regular, False otherwise.
   :rtype: bool

   .. rubric:: Examples

   >>> coverage.is_regular_grid()
   True
   >>> coverage.is_regular_grid(type="source")
   False
