find_point_index
================

.. py:method:: spatialetl.coverage.coverage.Coverage.find_point_index(target_lon, target_lat, decimal_tolerance=5, method='classic', only_mask_value=True, type='source')

   Find the index of the closest point to the given point.

   :param target_lon: Longitude of the target point.
   :type target_lon: float
   :param target_lat: Latitude of the target point.
   :type target_lat: float
   :param decimal_tolerance: Tolerance for rounding coordinates.
   :type decimal_tolerance: int, optional
   :param method: Method for calculation ("classic", "quick").
   :type method: str, optional
   :param only_mask_value: Whether to consider only mask values.
   :type only_mask_value: bool, optional
   :param type: Type of the grid ("source", "source_global").
   :type type: str, optional

   :returns: A list containing:
             [0] : the x index of the closest point
             [1] : the y index of the closest point
             [2] : the longitude of the closest point
             [3] : the latitude of the closest point
             [4] : the distance of the closest point in kilometers.
   :rtype: list

   .. rubric:: Examples

   >>> idx = coverage.find_point_index(5.0, 45.0)
   >>> idx = coverage.find_point_index(5.0, 45.0, method="quick", type="source_global")
