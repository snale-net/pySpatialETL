read_axis_x
===========

.. py:method:: spatialetl.coverage.coverage.Coverage.read_axis_x(type='target', with_overlap=False)

   Return the values (often longitude) of the x axis.

   :param type: Type of the grid ("target", "source", "target_global", "source_global").
   :type type: str, optional
   :param with_overlap: Whether to include overlap.
   :type with_overlap: bool, optional

   :returns: A one- or two-dimensional array of x axis values (often longitude): [x] or [y, x], depending on the grid type.
   :rtype: array

   .. rubric:: Examples

   >>> x_axis = coverage.read_axis_x()
   >>> x_axis = coverage.read_axis_x(type="source", with_overlap=True)
