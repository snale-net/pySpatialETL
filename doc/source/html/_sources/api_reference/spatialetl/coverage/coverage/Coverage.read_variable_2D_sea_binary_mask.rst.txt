read_variable_2D_sea_binary_mask
================================

.. py:method:: spatialetl.coverage.coverage.Coverage.read_variable_2D_sea_binary_mask(type='target', with_overlap=False)

   Read the land/sea mask over the entire coverage.

   :param type: Type of the grid ("target", "source").
   :type type: str, optional
   :param with_overlap: Whether to include overlap.
   :type with_overlap: bool, optional

   :returns: A two-dimensional array [y, x].
             0 = Land
             1 = Sea
   :rtype: array

   .. rubric:: Examples

   >>> mask = coverage.read_variable_2D_sea_binary_mask()
