get_x_size
==========

.. py:method:: spatialetl.coverage.coverage.Coverage.get_x_size(type='target', with_overlap=False)

   Get the x size.

   :param type: Type of the grid ("target", "source", "target_global", "source_global").
   :type type: str, optional
   :param with_overlap: Whether to include overlap.
   :type with_overlap: bool, optional

   :returns: The x size.
   :rtype: int

   .. rubric:: Examples

   >>> coverage.get_x_size()
   120
   >>> coverage.get_x_size(type="source", with_overlap=True)
   124
