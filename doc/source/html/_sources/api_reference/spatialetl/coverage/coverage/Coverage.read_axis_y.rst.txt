read_axis_y
===========

.. py:method:: spatialetl.coverage.coverage.Coverage.read_axis_y(type='target', with_overlap=False)

   Return the values (often latitude) of the y axis.

   :param type: Type of the grid ("target", "source", "target_global", "source_global").
   :type type: str, optional
   :param with_overlap: Whether to include overlap.
   :type with_overlap: bool, optional

   :returns: A one- or two-dimensional array of y axis values (often latitude): [x] or [y, x], depending on the grid type.
   :rtype: array

   .. rubric:: Examples

   >>> y_axis = coverage.read_axis_y()
   >>> y_axis = coverage.read_axis_y(type="source", with_overlap=True)
