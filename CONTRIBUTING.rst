Contributing to SpatialETL
=============================

Thank you for your interest in contributing to SpatialETL!

SpatialETL is an open-source ETL library for geospatial data processing, supporting various formats including NetCDF, GRIB, GeoTIFF, Shapefiles, and more.

Ways to Contribute
------------------

- Report bugs and propose new features via GitHub Issues
- Improve documentation and add examples
- Submit code changes and bug fixes
- Write tests to expand coverage
- Share your use cases and tutorials

---------------

For detailed contribution guides, see the `contributing-docs/ <contributing-docs/README.rst>`_ directory:

- `Local Development Setup <contributing-docs/02_local_virtualenv.rst>`_ - Environment setup with UV

- Check the documentation in `contributing-docs/ <contributing-docs/README.rst>`_
